# Personal Portfolio Website

A personal portfolio website developed to showcase my skills, projects, certifications, and professional profile as a BSc Information Technology student at North-West University.

## 🌐 Live Website

**[View my portfolio](https://retshedimokadi.netlify.app/)**

## 👩🏽‍💻 About

This website serves as my online portfolio and virtual CV. It provides an overview of my academic background, technical skills, projects, certifications, and contact information.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

## ✨ Features

* Responsive portfolio design
* Interactive navigation
* Smooth scrolling
* Mobile-friendly navigation menu
* Typing animation
* Skills showcase
* Project showcase
* Certifications section
* Contact and social media links
* Responsive design for different screen sizes

## 📂 Sections

* **Home** – Introduction and quick links
* **About Me** – Academic background and professional profile
* **Skills** – Programming languages, web technologies, and development tools
* **Projects** – Selected academic and personal projects
* **Certifications** – Completed professional certifications
* **Contact** – Ways to get in touch
